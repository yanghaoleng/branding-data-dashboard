# 实施范围与验收

用户最终范围：自媒体数据优先；达人数据和媒体发稿暂不开发。首版统计严格遵守上传PRD按发布时间筛选、最新有效累计快照、缺失不填零。

## 页面与问题映射

- 传播总览：四项KPI、发布日期分布、平台横向条形和可展开明细、账号搜索排序分组、TOP内容证据。
- 内容分析：传播集中度、主题分布、观看/互动散点、人工议题与标题规则。保留样本、来源和覆盖边界。
- 数据采集：账号配置、6/12/24小时同步、任务日志、候选身份核实、导入入口、本机采集器说明。

本任务是具有持久后端及账号管理的产品应用，因此使用独立React布局；采用数据看板技能的指标、来源、筛选、分析和核验规则，未使用固定数据快照的可编辑报告壳层。参考其业务表现案例的统一筛选和概览到实体下钻组织。

## 完成与剩余

已完成应用、导入、任务协议、存储、访问控制、透明规则分析、原始字段下钻、部署配置。

真实平台采集仍需：确认JOJO账号稳定身份、用户完成自有账号登录、逐平台核实选择器和字段、对照后台检查分页及完整范围、多日复测。当前无实号PoC通过记录，不将候选或搜索摘要当正式数据。

## 测试

- 8项JS测试：北京时间、发布时间筛选、身份排除、最新快照去重、null/不适用、过期、CSV与精确计数。
- 18项存储测试：幂等、整批校验、账号隔离、新旧快照、口径、全量声明、任务隔离/租约、失败保留、人工标签、未来时间、CSV预校验、级联移除。
- 本地HTTP：健康200；匿名dataset401；管理员200；采集器不能读取管理员dataset（401）。
- 本地浏览器：平台+本周筛选、分析联动、内容证据弹窗、正式空间登录均通过。
- 未通过/未执行：真实平台登录、三平台真实抓取、多日稳定性（缺少实号身份和授权登录）。

线上验证：HTML、JS、CSS与本地发布产物逐字节/哈希一致；健康200、匿名正式数据401、管理员200、采集器读取正式数据401；主页200。前端release为20261022-v4，API为20261022-v2。
手机视口工具未生效，移动端仅已实现响应式样式，未形成实际手机截图验收。线上浏览器自动化访问出现超时，线上HTTP/资源一致性验证不替代完整线上浏览器交互验收。
